# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [v1.0.0] - Initial Release

### Added
- Complete AI Practice Center with subject and chapter-wise modules.
- Student Hub dashboard for tracking upcoming tasks.
- Authentication via Supabase (Google OAuth and Email/Password).
- Dynamic 1-Page Revision Notes and Formula Sheets.
- PrepEntrance Circles (B2B community feature).
- Trial Gate mechanics (3-day free trial).
- Complete routing and protected routes layout.

### Changed
- Migrated from generic boilerplate to highly specialized JEE/NEET/CUET edtech platform.
- Updated authentication logic to support cohort-based routing.

### Fixed
- Payment checkout issues in Sandbox mode.
- Corrected question repetition behavior in fallback offline data bank.
